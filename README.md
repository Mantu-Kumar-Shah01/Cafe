# CafeDemo — Modern Luxury Café & Specialty Roastery

A high-end, editorial modern café web application crafted with **React 18**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features & Aesthetic

- **Visual Direction**: Editorial × Luxury × Warm Minimalism
- **Color Palette**:
  - Deep Espresso (`#1C1714`)
  - Cream (`#F7F2E8`)
  - Warm Sand (`#E8D8C3`)
  - Terracotta (`#B96545`)
  - Sage (`#7C8B72`)
  - Off White (`#FFFDF8`)
- **Typography**: Display serif fonts (*DM Serif Display*, *Cormorant Garamond*) paired with geometric UI fonts (*Manrope*, *Cinzel*).
- **Interactive Sections**:
  - **Cinematic Hero**: Staggered letter/word reveal animations, thermal precision badge, and live opening status.
  - **Signature Menu**: Dynamic sticky item preview cards, terroir specs, and tasting flight selector.
  - **Café Experience**: Asymmetrical split architecture showcasing the atmosphere.
  - **Coffee Journey**: 4-step interactive storytelling timeline (*Origin → Roast → Brew → Experience*).
  - **Our Story**: Heritage narrative with direct-trade metrics.
  - **Editorial Masonry Gallery**: Multi-aspect ratio gallery with category filters and full-screen Lightbox.
  - **Testimonials**: Editorial criticism and accolades carousel.
  - **Visit Us**: Location coordinates, transit guide, and copyable address.
  - **Table Reservation Modal**: Multi-step booking experience with celebratory confetti.
  - **Tasting Wishlist Drawer**: Side drawer for saving custom coffee flights.
  - **Custom Luxury Cursor**: Smooth spring-based cursor trail.

---

## 🛠️ Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Celebration FX**: Canvas Confetti

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Mantu-Kumar-Shah01/Cafe.git

# Navigate to directory
cd Cafe

# Install dependencies
npm install

# Run development server
npm run dev
```

### Production Build

```bash
# Compile TypeScript and bundle with Vite
npm run build

# Preview the production build locally
npm run preview
```
